# FlexStore

Website fictício de e-commerce desenvolvido durante o curso de **CSS Flexbox**.
O projeto foi idealizado para ser construído utilizando exclusivamente os conceitos de **Flexbox**, aplicando corretamente suas propriedades para garantir organização de layout, responsividade e acessibilidade.
Além disso, utilizei a metodologia de **CSS modular** para manter o código estruturado, organizado e escalável.

🔗 **[Confira o projeto aqui](https://joaovictorvm.github.io/FlexStore/)**

## Teclogias Utilizadas
- **HTML5 semântico**
- **CSS3**
- **CSS Flexbox**
- **CSS Modular**

## Features
- Estrutura HTML 100% semântica  
- Layout construído exclusivamente com **Flexbox**  
- Organização de estilos utilizando **CSS modular**  
- Site **100% responsivo**, explorando as propriedades do Flexbox

## 🛠️ Instalação e Uso

Clone o repositório:
```bash
git clone https://github.com/JoaoVictorVM/FlexStore.git
```
Acesse o diretório:
```bash
cd FlexStore
```
Abra o index.html no navegador.
Ou utilize uma extensão como **Live Server** no VS Code.
